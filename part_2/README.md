# Part 2 — MYH curated applications dataset

This folder contains the implementation workspace for Part 2 of the Data Pipeline Project.

## Working structure

```text
part_2/
├── instructions.txt
├── main.ipynb
├── README.md
└── data/
    ├── raw/
    │   ├── README.md
    │   └── .gitkeep
    └── processed/
        ├── README.md
        └── .gitkeep
```

## Folder roles

- `main.ipynb`  
  The single Part 2 notebook which is intended to become the complete raw-to-curated workflow.

- `data/raw/`  
  Original MYH Excel workbooks for application rounds 2020–2025. These are the immutable inputs.

- `data/processed/`  
  Notebook-generated curated exports. The final dataset will be written here in the validation/export stage.

## Notebook blueprint

The notebook is organized as a staged data journey:

1. Project purpose, scope, and design principles
2. Imports and runtime setup
3. Project paths and raw-data inventory
4. Source-file understanding
5. Why `Tabell 3` is used, and why `Tabell 4` is not merged
6. Initial curated-table design outline
7. Reusable ingestion and standardization
8. Cleaning, normalization, and enrichment
9. Validation and quality checks
10. Export of the curated dataset
11. SQL/API handoff note and final reflection

Sub-project 2.1 establishes this architecture and notebook skeleton. Later sub-projects fill in the implementation section by section.

## Raw vs processed strategy

- Raw Excel files stay unchanged in `data/raw/`.
- Processed outputs are generated by the notebook in `data/processed/`.
- The notebook should remain rerunnable from the raw files without manual intervention.
- Final exported data should be useful for the later SQL and FastAPI work.

## Optional helper code

No separate helper module is created at this stage. The project currently favors a clear, self-contained notebook.  
If later code becomes repetitive enough to justify helper functions outside the notebook, that choice should be made explicitly and documented.

## Sub-project 2.1 definition of done

This setup step is complete when:

- the Part 2 folder/data layout is settled,
- raw and processed data roles are explicit,
- the notebook contains a coherent section sequence aligned with the project roadmap,
